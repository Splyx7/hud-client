# Client Mod (Fabric, Minecraft 1.21.11)

Open the menu with Left Ctrl (change it in Options > Controls > Client Mod).
Sidebar > HUD editor: drag all HUD elements with the mouse.
Settings are saved in config/clientmod.json and config/clientmod_items.json.

Build: `gradle build`  (jar in build/libs, use the one without -sources)
Optional OneConfig page: `gradle build -Poneconfig` (needs OneConfig installed).
